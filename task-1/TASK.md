# Old-School task

## Task 1: Year to Century

Convert a year `convert(2026)` to its corresponding century. Example output:

```python
century = convert(2026)
print(f'Century: {century}') # Century: 21
```

## Task 2: Split the bill

Split a bill between `n` people equally: `split(amount, n)`. Return the list of amounts each
person pays. Example output:

```python
parts = split(100, 4)  # 100 CZK, 4 people
print(parts) # [25, 25, 25, 25]
```
